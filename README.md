# ✋ 摄像头手势区域滤镜 MVP

纯前端实时"手势区域滤镜"演示：在摄像头画面中，用一只手控制一个圆形滤镜区域，区域内实时应用模糊、像素化、放大镜、灰度等滤镜，区域外保持原始画面。

## 功能

- 摄像头实时画面（getUserMedia，640x480 起），默认镜像显示（自拍模式，可关）
- 同时识别两只手（MediaPipe HandLandmarker，numHands=2），每只手 21 个关键点、5 根手指分色标注，左下角实时显示各手手指坐标
- 滤镜区域：**每只手的拇指与食指之间**自动生成一个区域（最多两个区域同时生效）
  - 🤏 两指张得越开区域越大；区域大小滑块 50%~250% 全局缩放
  - ✊ 握拳 = 该手区域关闭
- 区域形状：矩形（方框）/ 圆形，软边缘，可随时切换
- 11 种滤镜：无 / 模糊 / 像素化 / 马赛克 / 瘦脸 / 放大镜 / 灰度 / 反色 / 怀旧 / 色相偏移 / 鲜艳
  - 马赛克：方块化 + 网格纹理
  - 瘦脸：MediaPipe FaceLandmarker 检测脸部关键点，对脸颊区域做向内收缩变形（滤镜框对准脸部即可看到效果）
- 软边缘圆形区域，位置与大小平滑过渡
- 鼠标模式兜底（无摄像头、无网络时也能演示）
- 无摄像头或未授权时自动进入演示模式（合成动画画面）
- 截图导出 PNG、FPS 显示、手势骨架可视化

## 运行

方式一（推荐，摄像头权限可用）：
1. 双击 start.bat（或运行 start.ps1）
2. 浏览器自动打开 http://localhost:8000
3. 允许摄像头权限即可开始使用

方式二：直接把 index.html 拖进浏览器（部分浏览器对 file:// 协议限制摄像头权限）。

## 手势说明

| 手势 | 效果 |
| --- | --- |
| 🖐 双手 | 每只手的拇指与食指之间自动形成一个滤镜区域（最多 2 个区域同时生效） |
| 🤏 两指张合 | 张得越开区域越大，捏得越紧区域越小 |
| ✊ 握拳 | 该手的滤镜区域关闭 |
| 🪞 画面镜像 | 默认开启（自拍视角），可取消勾选 |
| 🖱 鼠标模式 | 移动 = 移动区域，滚轮 = 缩放，单击 = 开关（无摄像头时用） |
| 💡 瘦脸 | 选择"瘦脸"滤镜并把区域对准脸部，人脸模型实时检测并做瘦脸变形 |

鼠标模式（点击"鼠标模式"按钮切换）：移动鼠标移动区域、滚轮缩放、单击开关滤镜。

## 技术栈

- HTML5 + Canvas 2D（滤镜合成：底层画面 + 区域蒙版 + 效果层）
- MediaPipe Tasks Vision（HandLandmarker 手部 21 点 ×2 手 + FaceLandmarker 人脸 478 点，CDN 加载）
- 纯前端，无后端依赖，无需构建

## 目录结构

    index.html         页面与 UI
    style.css          样式
    js/config.js       常量配置（视频尺寸、CDN 地址、半径范围）

    js/filters.js      滤镜定义与 Canvas 渲染管线

    start.ps1          一键启动本地服务（PowerShell）

## 摄像头无法访问？

应用会区分并提示具体原因，状态栏与黄色提示条会显示解决办法：

| 提示 | 含义 | 解决办法 |
| --- | --- | --- |
| 未检测到摄像头设备 | 系统里没有可用摄像头 | 连接/启用摄像头，或用「🖼 图片/视频源」加载本地图片/视频继续体验 |
| 权限被拒绝 | 浏览器阻止了摄像头 | 点击地址栏左侧的摄像头图标 → 允许 → 重试 |
| 摄像头被占用 | 摄像头正被其他软件使用 | 关闭会议软件/相机应用后重试 |
| 非安全上下文 | 页面不是 localhost/https | 用 start.bat 启动，不要直接双击 index.html |
| 设备不匹配 | 所选设备不支持当前参数 | 在「画面源」里换一个摄像头或选「自动」 |

另外：
- 高级：打开 http://localhost:8000/?src=图片或视频的相对路径（如 /demo.png）可启动时直接用该文件作为画面源，适合无摄像头演示


- 打开页面后先等状态栏出现「手势模型: 就绪」再开始操作
- 摄像头列表（画面源下拉框）会自动刷新；拔插摄像头后自动检测
- 没有摄像头时，可点击「🖼 图片/视频源」选择本地文件，配合「鼠标模式」完整体验区域滤镜

## 已知限制（MVP）

- 需要联网加载 MediaPipe CDN（jsdelivr，失败自动切 unpkg）
- 单只手、单区域；双区域/多手势留待后续版本
- 手势阈值基于归一化坐标，不同距离下需小幅调整
